# caveat-lang 0.1.0-rc.2

The second release candidate of the developer kit. It adds three changes that
came out of [authoring trial v3](../../experiments/agent-authoring/v3/RESULTS.md)
to [rc.1](v0.1.0-rc.1.md). It is **not published**: the package still
declares `private: true`, and publishing to npm (tag `next`) needs its own
authorization. See the [consolidation plan](../CONSOLIDATION_PLAN.md) for the
release sequence.

## What changed since rc.1

- **`caveat explain`** ([#18](https://github.com/WSattazahn/caveat-lang/pull/18))
  shows what a session decided and why: each decision, its grounds and
  lineage, every commit and reopening, and the evidence behind each displayed
  value. `--json` returns the same report as data.
- **A full history refuses the event**
  ([#21](https://github.com/WSattazahn/caveat-lang/pull/21)). A `sample` or
  `commit` on a reading stream or decision series that already holds its
  declared limit is refused as `limit/history_limit`, and the session
  continues. In rc.1 it was fatal `unclassified`.
- **Procedures over histories**
  ([#23](https://github.com/WSattazahn/caveat-lang/pull/23)). A procedure can
  take a reading stream (`s readings`) or a decision series (`d decisions`), so
  one procedure can serve several instruments.
