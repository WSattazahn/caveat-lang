## Behavior change: a later qualify reaches a value read through a decision (D015)

[Late Qualification 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-late-qualification-0.1.md)
promises that a later `qualify` reaches every current value whose evidence
includes the qualified evidence. On 1.0.x, a value set under `committed(…)`
after the `qualify` did not gain the caveat, although its evidence includes
it. On 1.1.0 it does
([Caveat Sources 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-caveat-sources-0.1.md)).
A record keeps the caveats it was made with, and `history_at` and `explain`
still read a decision's basis as recorded.

The change only adds caveats. No value loses one, and every event's outcome
is unchanged across the corpus sweep that spec describes. A save written by
1.0.x restores as it was recorded. `caveat check --records PROGRAM` lists
the rules that read a decision's record in a program that qualifies evidence
(C008). `caveat check --records --save SAVE PROGRAM` lists each saved value
that 1.1 would compute with a caveat the save lacks (C009). Both are reported
only when asked for.

## New in the language

- `commit … citing X, …`: a decision with grounds and no value
  ([Citing 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-citing-0.1.md)).
- `retaining C because E`: a caveat kept on purpose, with its reason
  ([Retention Reasons 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-retention-reasons-0.1.md)).
- `sample S = V` with no `supports` or `opposes`: a reading without a stance
  ([Neutral Sample 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-neutral-sample-0.1.md)).
- `sample S = V … noting TEXT`: keeps the observed text with the reading
  ([Reading Notes 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-reading-notes-0.1.md)).
- `reopened by changed STREAM`: reopen only when a reading's value changes
  ([Changed Triggers 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-changed-triggers-0.1.md)).
- `occurrence(E, N)` and `reading(STREAM, N)`: name an earlier occurrence of
  renewable evidence, or an earlier reading of a stream, in `withdraw`,
  `qualify`, `unqualify`, `reopen … because`, `observed`, `withdrawn` and
  `carries`
  ([Earlier Occurrence 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-earlier-occurrence-0.1.md),
  [Reading Index 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-reading-index-0.1.md)).
- `qualify latest(NAME) with C`, `unqualify latest(NAME) with C` and
  `carries(latest(NAME), C)`: doubt the current reading, take the doubt back,
  and ask whether it carries the caveat
  ([Latest 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-latest-0.1.md)).
- `rests_on_withdrawn(revision(SERIES, K))`: ask about a past revision of a
  decision
  ([Past Revisions 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-past-revisions-0.1.md)).
- `in_basis(DECISION, E)`: ask whether evidence is in a decision's grounds,
  current or of a past revision
  ([In Basis 0.1](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-in-basis-0.1.md)).

Each form did not load on 1.0.x, so no program that loads there changes
meaning. A 1.0 program that defines a source function named `in_basis` keeps
calling it.

A second `commit` of a plain commitment, one with no `decisions`
declaration, is refused as `evaluation/already_committed` (D008). On 1.0.x
it was fatal, so no event that was accepted is now refused.

## New in the kit

- `session.save({ compact: true })` writes a
  [replay save](https://github.com/WSattazahn/caveat-lang/blob/main/spec/caveat-replay-save-0.1.md),
  `caveat-replay-save/0.1`, which holds the accepted events. `runtime.restore`
  takes it like any save; a runtime before 1.1.0 does not.
- `session.snapshot()` straight after `dispatch` reuses that snapshot.
- `caveat check --unused` reports declarations nothing reads (C007).
- `caveat serve --state FILE` keeps the session in a state file and answers
  with the view.
- `decisionHistory(view, name)` lists every revision of a decision, retired
  ones included, and the starter gains `history()`.

## Fixes

- An `unqualify` clears a flag a value took through `examined(…)` (D019).
  On 1.0.x the flag stayed on the value after the take-back.
- The specs now agree that a decision's current revision, reopened or not,
  pins its grounds (D017). The runtime already behaved this way.
- The take-back and late-qualification fixes D012, D013, D014, D016, D018
  and D020 shipped in 1.0.1, 1.0.2 and 1.0.3 and are in 1.1.0.

The finding numbers refer to the
[decision log](https://github.com/WSattazahn/caveat-lang/blob/main/experiments/agent-decisions/README.md).
