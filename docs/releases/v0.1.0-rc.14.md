# CAVEAT Language 0.1.0-rc.14 — the MCP server name the registry accepts

**Release candidate, not yet published.** This file holds the release notes for 0.1.0-rc.14 while the candidate goes through `publish-npm.yml`, as rc.12 and rc.13 did. The tag, the tested artifact and the npm publication are recorded below only after the workflow's `verify-publication` job passes. The scope is described in the [rc.14 development record](https://github.com/WSattazahn/caveat-lang/blob/main/docs/releases/rc14-development.md).

## The MCP server name

rc.14 changes one thing in the package: its `package.json` declares `mcpName` `io.github.WSattazahn/caveat-lang`, and `server.json` names the server the same way. rc.13 declared `io.github.wsattazahn/caveat-lang`, all lowercase. The MCP Registry grants a GitHub login the namespace `io.github.` followed by the login exactly as GitHub spells it, and checks that the published package's `mcpName` equals the server name exactly, so the registry refused rc.13 and cannot list it. Published npm versions do not change, so the correction needs a new version.

The runtime, the language, the kit library, the CLI and the specifications are unchanged from rc.13. A program, save or event history that works with rc.13 works the same way with rc.14. See the [rc.13 release record](https://github.com/WSattazahn/caveat-lang/blob/main/docs/releases/v0.1.0-rc.13.md) for what rc.13 changed.
