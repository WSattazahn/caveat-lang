# caveat-lang 0.1.0-rc.1

The first release candidate of the developer kit: the reactive runtime, the
session library, the scenario runner and the packaged documentation. It is
tagged `v0.1.0-rc.1` at the commit below and **not published**: the package
still declares `private: true`, and publishing to npm (tag `next`) needs its
own authorization. See the [consolidation plan](../CONSOLIDATION_PLAN.md) for
the release sequence.

## Gates

**CI on the tagged commit (all passed).** Runtime run 36003474351, every job
passing. Legacy Door QA was skipped, because no runtime source changed since its
last run.

- **Core:**
  - rustfmt, clippy and the full test suite, run both with the default features
    and reactive-only (`--no-default-features`);
  - the third-party notices and the Pages gate's own tests;
  - the Slime Glow, elapsed-clock, structured-dispatch, Glowcap and Trail
    Rescue checks against the built WebAssembly;
  - the kit's session library and scenario runner, and the converted scenario
    suites;
  - the CLI and Map playthroughs.
- **Other runtime-workflow jobs:** the reproducible-WASM rebuild; the browser QA
  matrix; the VS Code extension; and the kit package test. The package test
  installs this exact tarball and uses it only through the install: the
  command, the library, a browser, and the getting-started guide followed step
  by step.
- **Separate workflows:** format-check run 36003474458, and the gated Pages
  deployment of the same commit, run 36005542083.

**Locally (all passed)**, at `753f6af`. Its runtime, kit, documentation and site
inputs are byte-identical to the tagged commit; the only difference is a
workflow trigger.

- fmt, and clippy with the default features and reactive-only;
- the reactive-only tests (459);
- a clean compiled build with the pinned toolchain;
- the author-study checks and the Glowcap divergence replay;
- both registered Glowcap differentials: `--round=6 --sequences=2000
  --ordered-decisions` against `caveat5`, seeds 6 and 7.

The default-feature tests (471) passed locally on the same test sources at
`5e6bbf3`.

**Found and fixed on the way.** At `555ea7f` the reactive-only clippy and
tests did not compile. Five test files used web sessions that exist only with
the `games` feature, and CI never built that combination. #17 gated those
tests and added both runs to CI. #19 added a manual trigger to the runtime
workflow, after GitHub dropped the push event for #17's merge and `main` went
untested.
