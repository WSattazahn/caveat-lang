Caveat plugin: privacy

The caveat plugin is a text skill. It contains instructions an agent reads and nothing else: no code that runs, no server, no network calls, no storage. It collects, stores and transmits no data. What you type stays with the agent and host you are using, under their policies, not ours.

If you also install the caveat-lang runtime, it runs locally on your machine; it makes no network connections and records only what your own program tells it to record.

Questions: github.com/WSattazahn/caveat-lang/issues.
