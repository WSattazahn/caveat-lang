Three agents, one record

Three agents contribute to one Caveat release ledger: Security checks a CVE mirror, Performance approves the canary using both its load run and Security's check, and Comms publishes release notes from the git log. When Security's CVE mirror turns out to be 14 days stale, withdraw it: only the decisions whose frozen grounds rested on it reopen — Comms's release notes stay in force, and every reopened decision keeps the exact grounds it was originally made on.

Runs locally in your browser on the Caveat WebAssembly runtime (loading…); nothing is sent anywhere. Caveat enforces each agent … sends … rule against the sender label the host supplies and records that label on every entry; it does not authenticate processes or verify that evidence is true (Limits).
