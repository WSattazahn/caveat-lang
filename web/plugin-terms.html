What the service is

The hosted server runs the published caveat-lang package's five authoring tools (validate, check, test, explain and dependents) on Caveat source and events you send it, and returns the report. It is free. It has no accounts and keeps nothing between requests.

What a result means

A Caveat report describes what a program does with the evidence supplied to it. Caveat does not check that the evidence is true, and a result is not advice and does not authorize any action. You and the agent you use stay responsible for what you do with it, under your own permissions.
